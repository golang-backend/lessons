1. 10 uzunlikdagi massiv e'lon qiling va elementlar bilan to'ldiring.
   Har bir elementni kvadratini ekranga chop eting.
   Example: 
   int: [1, 4, 6, 9]  out: 1, 16, 36, 81
2. Massiv e'lon qilin ... bilan va elementlardan eng katta qiymatni 
    ekranga chop eting.
    Example:
    int: [...]int{8, -9, 3, 5, 11, 0, -14}, out: 11

3. n uzunlikdagi massiv e'lon qiling, n bu ekrandan kiritilsin
    va n orqali massiv e'lon qilasiz va for loop orqali har bir 
    e'lementiga value kiritasin ekrandan o'qib.
    Example: 
    int: n = 5 arr[n] = arr[5]int{}
    index ga for orqali value ni ekranda o'qib assign qiling.

4. N uzunlikdagi massivda min va max sonlarni topib ekranga chiqarin.
  Example: int: [0, 4, 7, -1, 3, -9]  out: min: -9, max: 7
